### 数据依据（片中标注为"估算"）
- 食物：极寒体力消耗 3000–3500 kcal/天 → 30 天 90,000–105,000 kcal。方便面约 500 kcal/包 → ≈180 包；高能口粮约 4.5–5 kcal/g → ≈20 kg。
- 水：≥3 L/天 → 30 天 ≥90 L（≈180 瓶 500 ml）。从 −50°C 把 3 kg 雪化成 10°C 的水：升温 50 K×2.1 kJ + 熔化 334 kJ + 升温 10 K×4.2 kJ ≈ 480 kJ/kg → ≈1.4 MJ ≈ 0.4 kWh/天。
- 取暖：约 8–10 m² 的小避难所，20 cm 保温层（U≈0.2 W/m²K，外表面≈40 m²）+ 必要通风 + 冷桥，总热损失系数约 15 W/K；内外温差 60 K → 约 0.9 kW，人体自产约 0.1 kW → 需持续供热 ≈0.8–1.2 kW ≈ 20–30 kWh/天 → 30 天 ≈ 600–900 kWh，片中取中位 750 kWh。柴油取暖器（≈10 kWh/L，效率≈90%）→ ≈80 L。
- 对比：90,000 kcal × 4.184 kJ ≈ 376 MJ ≈ 105 kWh → 取暖能量 ≈ 食物能量的 7 倍。
- 电力：照明、通讯、CO 报警器、充电 ≈1 kWh/天 → 30 kWh。
- 药品：冻伤、低体温症、一氧化碳中毒（燃烧取暖必须通风 + CO 报警器）。

## 3. 视觉设计系统

**色彩**
| Token | 值 | 用途 |
|---|---|---|
| void | `#02060B` | 底色 |
| navy | `#061423` | 面板、地层 |
| ice | `#7FD8FF` | 主冷色、数据 |
| cyan | `#3BB8FF` | 发光、线条 |
| frost | `#E8F7FF` | 正文、冰 |
| dim | `#5C7A93` | 次要标签 |
| red | `#FF3B3B` | 警报 |
| orange | `#FF8A2A` | 热量 / 能量（全片唯一暖色，只给“热”） |
| ember | `#FFC15A` | 热核心高光 |

规则：冷色是环境，暖色只属于热源和能量——观众的眼睛会自动被橙色抓住，结论在色彩上提前成立。

**字体**
- 标题 / 字幕：Noto Sans CJK SC Black（900），字间距 0.02em，外发光 + 黑色描边阴影
- 大数字：Inter Display Black，tabular-nums
- HUD 标签：JetBrains Mono / DejaVu Sans Mono，全大写英文 + 中文，字间距 0.2em

**版式（1080×1920 安全区）**
- 顶部 HUD：y 60–190（模块编号、外部温度、DAY 计数）
- 主视觉区：y 200–1330
- 动态字幕：y ≈1360–1520，最多两行，关键数据橙/冰蓝高亮放大
- 底部进度条：y 1580（平台 UI 区之上）

**运动语言**
- 冲击：spring 缩放（2.2 → 1）+ 动态模糊 + 镜头震动（按冲击强度衰减）+ 白闪 + 色散
- 字幕：逐字下落 + 去模糊，1.1 帧错峰；高亮词整体放大
- 转场：所有场景切换落在 120 BPM 拍点，配合故障横切条
- 全局质感：胶片颗粒、扫描线、暗角、随温度增长的边缘结霜
